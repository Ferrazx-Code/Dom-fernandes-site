# Barbearia Dom Fernandes

Site em HTML único (`index.html`). Abra no navegador ou publique pelo GitHub Pages.

## Editar dados
- Telefone e mensagem do WhatsApp: constante `BIZ` no final do `index.html`.
- Endereço e horários: seções "Horários", "Como chegar" e rodapé, além do JSON-LD no `<head>`.
